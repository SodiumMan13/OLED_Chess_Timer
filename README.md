# OLED_Chess_Timer
A simple OLED chess timer PCB

It is a simple chess timer that I made because I like playing chess with my friend. I thought it would be a good idea to have a fun little chess timer while playing. It is powered by 3 AA batteries in a battery pack and is controlled by a Raspberry Pi Pico as the controller. The two main switches are keyboard switches, and the setting switches are tactile switches.
